# Record architecture decisions

Decisions that shaped this repo are written down as numbered Markdown files in `docs/adr/`, one decision per file, so a reader can tell why the repo is the way it is. Terms used in them are defined in `GLOSSARY.md`.

## Consequences

- A new decision gets the next number; a reversed one is superseded by a new ADR, not edited away.
